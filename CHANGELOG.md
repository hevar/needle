# Changelog

## 1.0.1

- Detect cloud-only notes by how long they take to load, without using Node.js APIs
- Keep searches responsive on mobile when notes are still downloading

## 1.0.0

First public release.

- Find in vault or in a folder, with match case, whole word and regular expressions
- Results grouped by note and ranked by relevance, modification time or path
- Live preview in source or reading view
- Resizable window and results/preview split
- Go to note, a quick switcher for notes, canvases and bases
- Background downloads for cloud-only notes
- Phone layout, keyboard navigation and screen reader support
